# HarnessAmp v2

HarnessAmp v2 focuses on mutation-based behavioral contract testing for high-stakes AI agents.

The v2 loop is:

```text
Load scenario -> Run baseline -> Apply mutations -> Rerun agent -> Diff traces -> Check contracts -> Gate release
```

## Current Slice

The first fully runnable slices are `FinanceGuard Core`, a personal-finance mutation pack, and `HealthGuard Core`, a healthcare mutation pack.

Run:

```bash
node scripts/harnessamp.mjs run examples/financeguard-basic/scenario.yaml --pack financeguard-core --fail-on critical
```

This runs a deterministic demo agent against the car-payment affordability scenario. The mutation sets `student_loan_payment` to `null`; the demo agent intentionally treats the missing value as zero and makes a definitive affordability recommendation. HarnessAmp reports a critical `missing_value_blindness` contract failure and blocks the gate.

Additional FinanceGuard scenarios live in `examples/financeguard-basic/scenarios/`.

Run the full FinanceGuard suite:

```bash
node scripts/harnessamp.mjs run examples/financeguard-basic --pack financeguard-core --fail-on high
```

## Catalog-Ready Pack Manifests

CustomerCareGuard and LegalGuard are represented as implementation-grade manifests in `src/v2/domain-pack-catalog.js`.

CustomerCareGuard tests operational safety under business-policy pressure:

- refund authority
- account-change authorization
- authentication before action
- privacy minimization
- policy source fidelity
- mandatory escalation
- abuse containment
- ethical cancellation
- security protection

LegalGuard tests legal-boundary safety under jurisdiction, deadline, confidentiality, and advice pressure:

- legal information boundary
- jurisdiction discipline
- deadline safety
- confidentiality protection
- contract source fidelity
- rights and obligations balance
- qualified counsel escalation
- urgent legal triage
- unlawful-evasion refusal

Both manifests use the standard v2 pack shape:

```text
positioning
contracts
mutationFamilies
curatedScenarios
failureTaxonomy
generatedMatrix
sourceHierarchy
authorityModel
expectedToolUse / forbiddenToolUse
```

Their generated suite scale is now sized to match the existing v2 packs:

| --- | ---: | ---: | ---: | ---: |
| CustomerCareGuard | 400 | 3,600 | 18,000 | 54,000 |
| LegalGuard | 400 | 4,200 | 21,000 | 63,000 |
