# Contributing

Thanks for helping improve HarnessAmp.

## Local workflow

1. Install dependencies with `npm install`.
2. Run the app with `npm run dev`.
3. Run checks with `npm test` and `npm run build`.
4. Update the docs in `docs/` when you change a user-facing workflow.

## Good changes

- Keep the UI and CLI output aligned.
- Add tests for scoring changes.
- Prefer small, focused commits.
